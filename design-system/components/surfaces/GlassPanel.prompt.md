The default raised surface — use it for anything floating over the world.

```jsx
<GlassPanel style={{ padding: 18 }}>
  <Eyebrow>Vigil</Eyebrow>
  <p>Three charges remain.</p>
</GlassPanel>
```

Don't add a radius or a coloured border. For a full-screen overlay use Modal instead.

## Accessibility

Choose `as` and ARIA attributes for the content's real role; translucent styling does not make a dialog.
