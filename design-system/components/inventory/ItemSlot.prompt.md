A pack slot. Six-column grid.

```jsx
<ItemSlot icon="ore" count={14} name="Ember-Iron"
  detail="A warm cinderward ore." />
```

Use the `Icon` name for the item class. There is no emoji or character fallback in this system.

## Accessibility

Interactive slots are native buttons named with item, quantity, and relevant state. Empty slots are not focusable.
