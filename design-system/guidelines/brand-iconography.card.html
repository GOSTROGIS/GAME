Thirty-five icons cover the eighteen disciplines, eight item classes, and the navigation and HUD set. Because every mark is a path inheriting currentColor, icons pick up hover and disabled states for free and cannot introduce a colour outside the palette.

Emoji are prohibited. So are icon fonts, raster icons, and bare Unicode characters used as icons. The game data still carries emoji on eleven of the eighteen skill records; that is a defect to fix in the data, never a pattern to copy. If a mark is missing, add a path to ICON_PATHS.
