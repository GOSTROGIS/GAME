# Sable Reach Bestiary Art

This directory contains the complete set of 21 canonical bestiary-family concept plates, plus one archived Glasswood alternate.

Included families:

- Ashbound
- Cairn Beasts
- March Deserters
- Drowned Parish
- Reed Coven
- Kilnforged
- Glasswood Brood
- Hush Order
- Echo Choir
- Ossuary Vermin
- Bell Revenants
- Salt-Waste Pilgrims
- Veil-Coast Kin
- Shuttered Ward
- Charnel Measures
- Black Sluice
- Last Pest Cart
- Breath Tithe
- White Ague
- Pallid Root Communion
- Anchored Quarantine

The PNGs are canonical concept masters for visual development. They are not transparent sprites, runtime billboards, production character models, proof that every family is playable, or physical-GPU performance evidence. `runtimeIntegrated` and `productionAssets` remain false in `../art-index.json`.

Generation prompts, review notes, lineage, rights declarations, dimensions, and maturity flags are recorded in the batch documentation and matching provenance files. The White Ague record in batch 04 identifies the accepted connectivity repair and the rejected source it supersedes.

Family-level visual direction is complete. The 178 individual bestiary masters and their 178 cutouts remain future subject-level production; family plates do not substitute for those forms. The authoritative coverage ledger is `../ART_ROSTER.md`, and the machine-readable path map is `../art-index.json`.

Large-scale raster production still requires confirmation of Git LFS capacity and the repository's path-specific raster validation workflow.
