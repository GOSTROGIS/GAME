## Cutout extraction and repair

Each approved master was submitted separately using this extraction template with the character name substituted. The image tool returned an RGB checkerboard render, so the repository's conservative `scripts/repair_checker_alpha.py` converted only boundary-connected pale low-chroma pixels to alpha. The final files were then checked for RGBA mode, transparent corners, substantial transparent background, a non-empty visible silhouette, dimensions, bytes, and SHA-256.

```text
Use case: background-extraction
Asset type: Sable Reach prototype named-NPC transparent cutout for <CHARACTER>
Input images: Image 1 is the sole edit target and identity source.
Primary request: Remove only the flat near-black background and replace it with genuine transparent alpha.
Constraints: preserve the complete character exactly—identity, face, age, expression, hair, pose, proportions, clothing, equipment, colors, lighting, and full silhouette. Preserve fine hair, frayed cloth, straps, tools, boots, and equipment edges. Keep the same canvas framing and do not crop. No checkerboard pattern, no opaque backdrop, no halo, no added floor shadow, no new objects, no text, no logo, no watermark. Output must be a real transparent-background PNG.
```
