## Cutout extraction and repair

Each approved master was submitted separately with a background-extraction prompt that locked identity, pose, proportions, clothing, equipment, colors, lighting, scale, framing, and full silhouette while requesting genuine alpha. The image tool returned RGB checkerboard renders. `scripts/repair_checker_alpha.py` therefore converted only boundary-connected pale low-chroma pixels to alpha. Each result was conformed to its 1024×1536 master canvas, optimized as an indexed 8-bit PNG with `tRNS`, and checked for transparent corners, substantial transparent background, a non-empty visible silhouette, edge integrity over contrasting backgrounds, dimensions, bytes, and SHA-256.

```text

Asset type: Sable Reach transparent named-NPC cutout for <CHARACTER>
Input images: Image 1 is the sole edit target and identity source.
Primary request: Remove only the near-black studio background and return a clean full-body cutout on a genuinely transparent background.
Constraints: change only the background. Preserve the exact character identity, face, hair, expression, pose, anatomy, clothing, armor, equipment, hands, boots, lighting, colors, textures, scale, canvas proportions, and complete silhouette. Preserve fine hair, rope, chain, reed, metal, and frayed cloth edges. Four corners must be transparent. No baked checkerboard, matte rectangle, halo, crop, resizing, restyling, added or removed object, text, logo, or watermark.
```
