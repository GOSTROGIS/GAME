# Slipcurve seed bridge

This authoring tool reads a pinned, owner-authorized Slipcurve sitelib snapshot
and emits deterministic **prototype seed data**. It never reads SVG geometry,
never inverse-projects isometric output, and never writes to the source tree.

The source path is deliberately explicit:

```powershell
node tools/assets/slipcurve-bridge/refresh.mjs --source-root "C:\path\to\MONTE CARLO" --write
node tools/assets/slipcurve-bridge/refresh.mjs --source-root "C:\path\to\MONTE CARLO" --check
node tools/assets/slipcurve-bridge/test.mjs
node tools/assets/slipcurve-bridge/verify-snapshot.mjs
```

`source-lock.json` is the complete read allowlist. A changed file, symlink/path
escape, wrong Git head, wrong source commit, or wrong Chromium build fails
before capture. Unrelated dirty source files are ignored because they are never
opened.

Generator code is instrumented in memory with the TypeScript JavaScript AST.
Supported model-space primitives are captured before projection under iso,
top, and side runs. Screen-space output, annotations, people, animals,
unrecognized raw SVG strings, nonuniform radial fits, render failures, and
view-dependent structure are quarantined with evidence. Historical review
rejections remain rejected.

Generated authoring indexes live under
`packages/content/manifests/slipcurve-seeds/`. Representative neutral GLBs
live under `assets/3d/seeds/slipcurve/`. They are always
`prototype_geometry`, are never production-eligible, and are not imported by
the content package's eager barrel.

`lib/glb.mjs` exports `primitiveSceneToGlb()`, `primitiveLodSceneToGlb()`, and
`writePrimitiveSceneGlb()` for deterministic downstream reskin tooling. The
seed path remains neutral; the runtime derivative builder authors new dark
materials and three independently simplified LOD nodes without retaining the
source palette or any source primitive. Source bounds contribute only a
clamped proportion hint; asset-specific Sable patterns author every runtime
silhouette, damage break, and three-way semantic material partition.

The Sable Reach runtime derivative pass is separate and source-tree independent:

```powershell
pnpm bridge:runtime:build
pnpm bridge:runtime:check
```

It resolves 96 accepted-seed lineages, writes their prototype GLBs under
`assets/3d/runtime/bridge/`, and records measured hashes/GPU storage in the
runtime and lineage manifests. Full validation also requires an exact
declared-vs-disk asset set, self-contained GLBs, unique authored pattern
evidence, dimensioned scene colliders, and a red strict-production gate.

Normal pull-request CI fetches the 24 representative seed GLBs and validates
all 1,087 catalog contracts. The separate full-LFS workflow fetches and cycles
the complete 96-derivative runtime closure across all seven proof sites.

`verify-snapshot.mjs` validates the committed shard and GLB hashes without
opening or depending on the source repository. `refresh.mjs --check` is the
stronger reproducibility gate: it reruns the pinned source capture and compares
every generated byte.
